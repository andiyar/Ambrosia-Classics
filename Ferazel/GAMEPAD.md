# Ferazel's Wand — playing with a controller

A game controller works out of the box: a **Nintendo Switch Pro Controller**, Joy-Cons, an Xbox or a PlayStation
pad — whatever macOS recognises as a game controller. The controller simply presses the game's own keys for you, so
the game itself plays exactly as the original. No setup inside the game.

## The buttons

Buttons go by position, so the Switch's and the Xbox's swapped A/B and X/Y labels don't matter. The d-pad and the left
stick both move.

| What it does | Switch | Xbox | PlayStation |
|---|---|---|---|
| **Move / climb / duck** (in a level) | d-pad or left stick | d-pad or left stick | d-pad or left stick |
| **Jump / swim** | B (bottom) or A (right) | A (bottom) or B (right) | ✕ or ○ |
| **Run** | Y (left), ZL or ZR | X (left), LT or RT | □, L2 or R2 |
| **Use item / cast** | X (top) | Y (top) | △ |
| **Previous / next item** | L / R | LB / RB | L1 / R1 |
| **Pause / un-pause** (in a level) | **+** | Menu (☰) | Options |
| **Abort the game** (in a level) — hold for 1 second | **−** | View (⧉) | Create / Share |
| **New Game** (main menu) | B, A or **+** | A, B or Menu | ✕, ○ or Options |
| **OK / continue** (everything else) | any face button or **+** | any face button or Menu | any face button or Options |
| **Back / skip** (everything else) | **−** | View | Create / Share |

Everywhere outside a level (the world map, the death screen, the chapter cards, the "OK" messages) the d-pad presses
the arrow keys and every face button presses Return. In a conversation the d-pad moves through the answers and a face
button picks one; **−** ends the conversation, as Esc does.

## Remapping

In a level the controller presses the keys chosen in **Options** (Game ▸ Preferences…): move, jump, run, use and the
item keys follow them, so changing a key there changes the button too. Pause stays on **+** and abort on **−**.

## Things to know

- **No pointer.** Continue, Options and Credits on the main menu, the Options dialog and the saved-game file windows
  need the mouse or keyboard. A controller starts a New Game only.
- **−** in a level asks "abort this game?" the way Esc does — only after a 1-second hold, so a stray press does
  nothing. A face button answers OK (the game ends); to carry on, click Cancel — the original's question ignores Esc,
  so **−** cannot cancel it. On the world map **−** asks at once, as Esc does there.
- The game is paused while the controller's pause **or** the keyboard's Caps Lock is on — both must be off to play on.
- While paused only **+** does anything; use the mouse for the menu bar (Abort Game, Preferences…).
- The controller works only while the game is the front app, like the keyboard.

## Pairing a Switch Pro Controller with the Mac

1. On the Mac, open **System Settings ▸ Bluetooth** (leave the window open).
2. On the controller, hold the small round **sync button** on its top edge until the green lights run back and forth.
3. "Pro Controller" appears in the Bluetooth list — click **Connect**.
4. Open Ferazel's Wand.

## Check with a real controller (for Ben)

1. Main menu: press a face button → a new game starts.
2. Move with the d-pad and with the left stick; jump with the bottom and right buttons; run with the left button.
3. **+** pauses; **+** again un-pauses.
4. Tap **−** → nothing; hold it a second → the abort question.
5. On the world map, the d-pad walks and a face button enters a level.
