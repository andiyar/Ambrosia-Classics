# Bubble Trouble X — playing with a controller

A game controller works out of the box: a **Nintendo Switch Pro Controller**, Joy-Cons, an Xbox or a PlayStation
pad — whatever macOS recognises as a game controller. The controller simply presses the game's own keys for you, so
the game itself plays exactly as the original. No setup inside the game.

## The buttons

Every face button does the same thing, so it never matters which one is "A". The d-pad and the left stick both move.

| What it does | Switch | Xbox | PlayStation |
|---|---|---|---|
| **Move** (in a game) | d-pad or left stick | d-pad or left stick | d-pad or left stick |
| **Push** (in a game) | A, B, X or Y | A, B, X or Y | ✕, ○, □ or △ |
| **Pause / un-pause** (in a game) | **+** | Menu (☰) | Options |
| **End the game** (in a game) — hold for 1 second | **−** | View (⧉) | Create / Share |
| **Start / OK / continue** (title screen, scores, credits, dialogs) | A, B, X, Y or **+** | A, B, X, Y or Menu | ✕, ○, □, △ or Options |
| **Cancel** (dialogs) | **−** | View | Create / Share |

Shoulder buttons, triggers and stick clicks do nothing. While a demo plays, a face button, **+**, **−** or the d-pad ends
it, as any key does. Outside a game the d-pad presses the arrow keys (the title screen ignores them).

## Pairing a Switch Pro Controller with the Mac

1. On the Mac, open **System Settings ▸ Bluetooth** (leave the window open).
2. On the controller, hold the small round **sync button** on its top edge (between the USB-C port and the
   shoulder buttons) until the green lights run back and forth.
3. "Pro Controller" appears in the Bluetooth list — click **Connect**.
4. Open Bubble Trouble X.

Once paired, pressing the controller's **Home** button reconnects it later. If it was last used with the Switch,
pair it again as above.

## Remapping

The controller follows the key set chosen in **Preferences ▸ Keys** (or **Options ▸ Key Sets**): move and push press
that set's five keys, so changing a key there changes the button too. Pause stays on **+** and end-game on **−**.

## Things to know

- **− ends a game only while it is running, not while paused** — the original reads Esc only in play. Un-pause with
  **+** first.
- With **Preferences ▸ Misc ▸ "Hold Escape to exit"** ticked, the hold is about **2 seconds** (1 s before the
  controller presses Esc, then the game's own hold).
- **No typing names with the controller.** When you get a high score, a face button is OK and accepts the name
  already in the box (the last one entered). Use the keyboard to type a new name.
- In a dialog opened during a game (Preferences… while paused), **+** still pauses / un-pauses; a face button
  is OK there.
- The controller works only while the game is the front app, like the keyboard.

## Check with a real controller (for Ben)

1. Title screen: press a face button → a new game starts.
2. Move with the d-pad and with the left stick.
3. Push a block with each of the four face buttons.
4. **+** pauses (PAUSED shows); **+** again un-pauses.
5. Hold **−** for a second → the game ends; a tap does nothing.
6. High-score name dialog: a face button = OK (the name is kept).
