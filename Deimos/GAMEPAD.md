# Deimos Rising — playing with a controller

A game controller works out of the box: a **Nintendo Switch Pro Controller**, Joy-Cons, an Xbox or a PlayStation
pad — whatever macOS recognises as a game controller. The controller simply presses the game's own keys for you, so
the game itself plays exactly as the original. No setup inside the game.

**One controller, for player 1.** If more than one is connected they all act as player 1's. Player 2 plays on the
keyboard.

## The buttons

Buttons go by position, so the Switch's and the Xbox's swapped A/B and X/Y labels don't matter. The d-pad and the left
stick both move.

| What it does | Switch | Xbox | PlayStation |
|---|---|---|---|
| **Fly** (in play) | d-pad or left stick | d-pad or left stick | d-pad or left stick |
| **Fire air weapon** | B (bottom) | A (bottom) | ✕ |
| **Fire ground weapon** | Y (left) | X (left) | □ |
| **Select the next air weapon** | X (top) or A (right) | Y (top) or B (right) | △ or ○ |
| **Pause / un-pause** (in play and on the level select) | **+** | Menu (☰) | Options |
| **Leave the game** (in play) — hold for 1 second | **−** | View (⧉) | Create / Share |
| **Level select:** previous / next sector | d-pad or stick left / right | the same | the same |
| **Level select:** start the sector | any face button | any face button | any face button |
| **Level select:** back to the menu | **−** | View | Create / Share |
| **Main menu:** 1 PLAYER | any face button or **+** | any face button or Menu | any face button or Options |
| **Everywhere else** (scores, name entry, credits, the settings window): OK / continue | any face button or **+** | any face button or Menu | any face button or Options |
| **Everywhere else:** arrows | d-pad or left stick | d-pad or left stick | d-pad or left stick |
| **End a demo** | **−** | View | Create / Share |

On the main menu and every screen outside play, the d-pad presses the arrow keys, every face button and **+** press
Return, and **−** presses Esc. The shoulder buttons and triggers do nothing.

## Remapping

In play the controller presses player 1's keys as set in the game's controls window — the **PREFERENCES** button on
the main menu, then **Set Controls…**: change a key there and the button follows it. Pause stays on **+** and leave on **−**.

## Things to know

- **2 PLAYER needs the keyboard or the mouse** (press 2, or click the button): the controller starts a one-player game.
- **−** in play works only after a 1-second hold, so a stray press does nothing; it then does what Esc does, so the
  game's own "Hold Escape" setting applies on top. With that setting on, a quick tap of **−** on the level select or
  in a demo does nothing either, as with the keyboard's Esc.
- The game is paused while the controller's pause **or** the keyboard's Caps Lock is on — both must be off to play on.
- **The controller is switched off while the Set Controls… window is open,** so a button press can never be taken as a
  key for a player. Use the keyboard there.
- The settings window's boxes and sliders need the mouse (a face button there presses Save, as Return does), and so
  does the "erase all scores?" question.
- The controller works only while the game is the front app, like the keyboard.

## Pairing a Switch Pro Controller with the Mac

1. On the Mac, open **System Settings ▸ Bluetooth** (leave the window open).
2. On the controller, hold the small round **sync button** on its top edge until the green lights run back and forth.
3. "Pro Controller" appears in the Bluetooth list — click **Connect**.
4. Open Deimos Rising.

## Check with a real controller (for Ben)

1. Main menu: press a face button → the level select comes up.
2. Level select: d-pad left and right change the sector; a face button starts it.
3. In play: fly with the d-pad and with the left stick; fire with the bottom and left buttons; the top button selects
   the next air weapon (from sector 2 on).
4. **+** pauses; **+** again un-pauses.
5. Tap **−** → nothing; hold it a second → the game ends, as Esc does.
6. On the main menu click **PREFERENCES**, then **Set Controls…**: the controller does nothing there.
