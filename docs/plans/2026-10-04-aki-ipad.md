## 2. Architecture contracts

- **C1 — One codebase, two shells.** Shared Swift in `Aki/App/` stays shared; Mac-only files move to `Aki/App/Mac/`,
  iPad-only to `Aki/App/iOS/` (or `#if os(...)` inside a file where the split is a few lines). AkiCore stays
  Foundation-only (D6 portability shape) and gains `.iOS`.
- **C2 — Continuation-passing modals, synchronous on the Mac.** Every modal call site in shared code becomes
  `present(<modal>) { result in … }`. The **Mac** implementation runs `NSApp.runModal` and calls the completion before
  returning — so Mac behaviour (including timer ticks under the modal, the Q25 edge) is unchanged by construction. The
  **iPad** implementation presents an overlay and calls the completion on dismissal; the idle timer keeps ticking (as on
  the Mac's `.common`-mode timer). `perform(_:)` must hold the events after `.dialog(0x47)` and resume them in the
  completion (an index into the event list), never re-enter with a half-run list.
- **C3 — Platform-neutral input.** `AkiScreen` / `ShellInputHandler` take a neutral `ShellClick(point, timestamp,
  modifiers)` and `ShellKey(code, modifiers)` instead of `NSEvent`. The double-click guard reads a per-platform interval
  (Mac: `NSEvent.doubleClickInterval`; iPad: 0.5 s constant). A tap is a click at the touch point in logical 800×600
  coordinates; `getMouseLocation` returns the last touch point on iPad. Hover (R2) via `UIHoverGestureRecognizer`.
- **C4 — Dialogs drawn from the same nib XML.** The iPad dialog runner lays the Carbon/Cocoa nib controls out at their
  nib frames, centred in the 800×600 canvas space and scaled with it, in a system font substituted for LucidaGrande;
  push buttons/checkboxes as plain UIKit controls styled close to Aqua. Return/Esc via `UIKeyCommand`.
- **C5 — Menus (per R1).** `AkiMenus` gains a `UIMenuBuilder` path that builds the same commands + key equivalents from
  the same nib XML; enabling follows the existing validation (`undoEnabled` etc.).
- **C6 — Build.** New xcodegen target `AkiPad` (platform iOS, floor per R5, `TARGETED_DEVICE_FAMILY 2`, team
  `5W72UJL332`, Automatic signing, `Info-iOS.plist`: `UILaunchScreen`, scene manifest, landscape-only `~ipad`, status bar
  hidden, `UIRequiresFullScreen`, `UIAppFonts` OsakaMono, `CFBundleDevelopmentRegion` English); a pre-sign script phase
  rsyncs `$AKI_DATA_12` into the flat `.app` root unchanged (`ENABLE_USER_SCRIPT_SANDBOXING NO`, `COMPRESS_PNG_FILES NO`).
  The data stays git-ignored. Mac target untouched.

3. Dialog look — no Aqua on iPad; C4 is "close", not pixel-identical. Ben's eyes decide.
4. HectorKit coordination (R6) — two sessions writing HectorKit must not overlap; `git worktree list` in both repos first.
5. Osaka-Mono redistribution on a sideloaded build — private install only; no change from the Mac staging.
