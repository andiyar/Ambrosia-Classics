## Non-negotiable invariants

These override any task step if they ever conflict.

1. **100% replica, 1.2.0 column.** No modern affordances, nothing the original lacks, no per-element
   commissioning questions (standing ruling EV D30/D67). Behaviour comes from the bank; where the
   bank is MED/LOW/NOT RESOLVED, implement its best reading and keep the §S6 row.
2. **Original data, original names.** The app loads every PNG/AIFF/MP3/strings/nib/rtf/pdf from its
   own `Contents/Resources` by the shipped file name — no renaming, no atlases, no re-encoding,
   no transcribed strings where the shipped `Localizable.strings` / nib XML carries them.
3. ⚠️ **LANDMINE — never commit derived data.** `Resources/`, `out/`, `ghidra/*` (except scripts),
   `.build/`, `*.xcodeproj` are git-ignored (`.gitignore` lines 2–10). Never `git add -A`/`.`; add the
   exact paths each Commit lists; after each commit `git -C "$WT" status --porcelain | grep -v '^??'`
   prints nothing.
4. ⚠️ **LANDMINE — never hand-edit the pbxproj.** `project.yml` is the truth; `xcodegen generate`
   rewrites `AmbrosiaClassics.xcodeproj` (ignored). New `Aki/App/*.swift` files are picked up by
   regeneration; never add them by hand.
5. ⚠️ **LANDMINE — HectorKit `Package.swift` is append-only.** v0.1.0's file (`f578925`) is final for
   Phase 0; P1.1 appends the exact block it shows; never replace the file; the three libraries,
   `HectorTestSupport` and the three test targets stay byte-identical. The recorded floor
   (`tools/check-zero-skip.sh` `FLOOR=`) rises by exactly the new test count in the same commit.
6. ⚠️ **LANDMINE — extend Phase 0's `Aki/Core`, never replace it.** `Aki/Core/Package.swift`,
   `Sources/AkiCore/AkiBundle.swift`, `Sources/aki-census/` are not modified by this plan; Phase 1 needs
   no `Package.swift` change (new files land in the existing `AkiCore` / `AkiCoreTests` targets; AkiCore
   stays AppKit-free). The ONE Phase-0 edit: P1.3 moves `AkiCensusTests.swift`'s file-private locator
   (`akiResources(_:defaultApp:)`, `aki11()`, `aki12()`) verbatim into a shared test file so every test
   file reuses that exact name and shape. If a later task must add a target: fetch `origin/main`,
   ADD products/targets, keep the library name `AkiCore`.
7. **The prefs blob is the 143-byte `GameSettings` layout of `file-formats.md` §2.2** — not a new
   format, not Codable, not one key per field. The replica writes it with `UserDefaults.set(_:forKey:
   "GameSettings")`.
8. ⚠️ **LANDMINE — Swift 6 strict concurrency.** App code and HectorShell's AppKit/AVFoundation types are
   `@MainActor`; AkiCore value types are `Sendable` structs (`CocoaNib`/`CarbonNib` hold `XMLElement`
   and are deliberately NOT `Sendable`). Timer/delegate callbacks hop with `@objc` selectors on
   `@MainActor` classes or `Mutex` (see HectorShell `ShellSoundBank`). No `nonisolated(unsafe)`, no
   `@preconcurrency` imports, no `@unchecked Sendable` on our own types.
9. ⚠️ **LANDMINE — SwiftPM rejects a declared target with no sources.** Declare `HectorShell` /
   `HectorShellTests` in the same commit that adds their first source files (P1.1).
10. ⚠️ **LANDMINE — symlinked start dirs.** Resolve symlinks before enumerating data folders
    (`URL.resolvingSymlinksInPath()`), as Phase 0's `akiResources()` does.
11. ⚠️ **LANDMINE — the boot smoke pollutes Ben's first launch.** Running the staged app clears the
    first-launch flag (welcome splash) in `com.ambrosiaclassics.aki`. Every smoke run ends with
    `defaults delete com.ambrosiaclassics.aki 2>/dev/null; true`. Launch with `open -g` (no focus steal;
    one launch per batch).
12. **Ticks, not wall clocks.** All timing that the original gates on `TickCount()` uses
    `ShellClock.ticks()` (60 Hz since boot, UInt32 wrap) and the 0.05 s `ShellIdleTimer` in the
    common run-loop modes (method-map §1 `applicationDidFinishLaunching:`), so cadences (map > 6
    ticks, game ≥ 2 ticks, flashes > 5) reproduce.
13. **QuickDraw pipeline mirrored, not re-imagined.** The original composes into GWorlds and copies to
    the window (`_DrawToGWorld` @ 0x4a04, `_DrawToWindow` @ 0x4b40). The replica keeps the same
    buffers (`AkiGWorlds`) and the same rects (`SetRect(left, top, right, bottom)` transcribed as
    `QDRect`/`ShellRect`), including the code's 1-px size mismatches that make QuickDraw stretch.
14. **Present path (orchestrator ruling → Classics DECISIONS D3, written in Task 0):** a CoreGraphics
    bitmap canvas presented through a CALayer-backed `NSView`; HectorShell's render smoke MEASURES the
    present cost at 3× (median < 4 ms/frame over 60 frames — scratch replica: 1.34 ms, debug build);
    Metal only if that budget is missed. No Metal task exists in this plan.
15. **No per-frame allocation on our side:** the canvas, every GWorld and the CGContext over each are
    allocated once; `present()` hands CoreAnimation a `CGContext.makeImage()` copy-on-write snapshot
    (CoreGraphics' own object, not a pixel buffer we allocate). Backgrounds are re-loaded per LEVEL,
    never per frame.
16. Commit trailer, every commit in both repos, and no other trailer:
    `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
17. **STOP on any unexpected number** (test totals, floor, PNG count, build result) — report the
    command output; never edit an expectation to match.

### S4. Resource loading
`AkiAssets` is the only file-system entry point: PNG via `ShellBitmap(contentsOf:)` from
`bundle.url(forResource: name, withExtension: "png")`; audio by exact file name; splash/preview/paper
`NSImage`s via `bundle.image(forResource:)`; strings via `bundle.localizedString(forKey:value:nil
table:nil)`; nib XML via `lproj("Preferences.nib/designable.nib")` with
`bundle.preferredLocalizations.first ?? "English"`, falling back to `English.lproj`. Under `#if DEBUG`
only: at launch `missingFiles()` non-empty → one `NSAlert` ("Aki's original data files are missing from
this app. Run tools/stage-aki.sh.") then terminate. The check (method and call site) is compiled out of the
Release build the stage script produces — the original has no such alert (Known delta 7).
