# Aki — what to expect (work in progress)

This is a **Phase 1 in-progress** build of the Aki — Mahjong Solitaire 1.2.0 replica, staged by
`tools/stage-aki.sh`. It is not a gate build: nothing here is ready for the honesty check yet.

What this build does today:

1. Double-click `Aki.app`. An 800×600 window titled "Aki - Mahjong Solitaire" opens, centred, showing
   the original map picture (`map.png`) loaded from the app's own bundle.
2. Nothing on the map responds yet — lanterns, hover previews, the difficulty bar, menus, sound,
   music, splashes and Preferences arrive in the following Phase 1 steps.
3. Quit from the Dock icon's menu (Quit) — the original menu bar, with ⌘Q, is built in a later step.

This page is rewritten at the Phase 1 gate.
